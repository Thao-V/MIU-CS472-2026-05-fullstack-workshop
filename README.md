# Workshop: Implement a Todo List App
## Main features:
1. Create a task
2. View all tasks
3. Mark task as completed
4. Edit task
5. Delete task
6. Login and Logout
## Tech Stack
* Programming Language: TypeScript
* FrontEnd: React, Tailwindcss, React Router
* Backend: Restful API, NodeJS, ExpressJS, CORS
## Requirement
1. Initialize the project from scratch
2. For each feature, follow the process below:
* Implement a Backend API
* Test with Thunder Client
* Implement Frontend 
* Connect Frontend with Backend
* Test the complete feature
